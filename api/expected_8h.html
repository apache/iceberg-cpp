Detailed Description

A C++20 backport of C++23 std::expected, used as the storage type behind iceberg::Result.

Purpose: the library is developed and built as C++23. Compatibility-mode packages additionally support C++20 consumers. iceberg::Result<T> (see iceberg/result.h) uses the same iceberg::expected type in both package modes rather than selecting a storage type per translation unit. The API mirrors std::expected (including the monadic and_then, or_else, transform and transform_error), so code can be written as if against the standard type.

Upstream: https://github.com/zeus-cpp/expected (MIT), include/zeus/expected.hpp at tag v1.4.0 (f9dde3b062f1b3a5d1a9f2888e4b6f6d2303557b).

Local changes (search for "iceberg:" for the non-mechanical ones):

  • Namespace zeus and its versioned inline ABI namespace replaced by plain iceberg, so symbol names stay stable across upstream updates; macros renamed from ZEUS_EXPECTED_* to ICEBERG_EXPECTED_*, and the upstream version macros removed.
  • Public classes annotated with ICEBERG_EXPORT, except the primary expected template, which uses ICEBERG_TEMPLATE_CLASS_EXPORT (empty on MSVC, where exporting a class template breaks the Windows build).
  • [[nodiscard]] added to unexpected and expected.
  • The default constructor no longer requires T to be default constructible, so expected<T, E> can hold types with no (or a private) default constructor, which MSVC otherwise tried to instantiate.
  • The default package retains construction from std::unexpected<G> when available. Compatibility packages omit those constructors in all language modes so the class definition remains the same for library and consumer.
  • Reformatted with clang-format.

History:

  • apache/iceberg-cpp#40 first vendored zeus-cpp/expected (v1.2.0) while the project targeted C++20.
  • apache/iceberg-cpp#139 raised the project to C++23 and removed the header in favor of std::expected, which made C++23 a requirement for users of the public headers too.
  • apache/iceberg-cpp#936 vendored it again, updated to v1.4.0, so the public headers work in C++20 again.

Once C++23 can be required of all consumers, this header can be dropped and iceberg::Result aliased back to std::expected.
