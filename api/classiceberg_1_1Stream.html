Detailed Description

template<typename T>
class iceberg::Stream< T >

A pull-based stream whose reads may fail.

Stream implementations own any resources needed to produce values. Destroying a stream releases those resources, including when consumption stops before reaching the end. Streams are not thread-safe unless an implementation explicitly says otherwise. Once Next() returns an error or std::nullopt, the stream is terminal. Subsequent calls return the same terminal result without invoking the implementation again.
