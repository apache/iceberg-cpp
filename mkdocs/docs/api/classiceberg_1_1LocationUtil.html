static std::string_view iceberg::LocationUtil::ParseScheme ( std::string_view  location)
static

Extract the URI scheme from a location.

This follows Java's ResolvingFileIO: the text before the first colon is the scheme; an empty result means that no scheme was found. Text that is not syntactically a scheme (RFC 3986) yields no scheme, and on Windows a single letter is a drive rather than a scheme. The rest of the location is not validated.
