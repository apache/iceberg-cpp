Detailed Description

AES GCM Stream format constants.

AGS1 stores the block length in its header. This implementation only reads and writes 1 MiB blocks, matching Java, rather than supporting other block lengths.

For Java compatibility, an empty file contains one zero-length plaintext block with a nonce and tag. The AGS1 spec describes a non-empty last block and does not explicitly define this empty-file representation.

Plaintext length of a stream with the given encrypted length.

Returns an error if the length is shorter than an empty stream, implies more than int32 max blocks, or ends in a block too short to hold a nonce and tag.
