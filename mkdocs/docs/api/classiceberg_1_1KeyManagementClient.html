Detailed Description

Wraps and unwraps secret keys with master keys kept in a KMS.

Mirrors Java's org.apache.iceberg.encryption.KeyManagementClient. The table master key (table property encryption.key-id) never leaves the KMS; it only wraps and unwraps the table's key encryption keys.
