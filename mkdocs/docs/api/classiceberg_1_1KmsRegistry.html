Detailed Description

Creates KMS clients by name.

Catalogs create their KMS client from the catalog properties, with the same property names as Java:

  • encryption.kms-type: a built-in client, aws, gcp or azure;
  • encryption.kms-impl: the name a custom client was registered under.

Java has no built-in clients yet and rejects every encryption.kms-type (EncryptionUtil.createKmsClient); here the type names resolve through the same registry, so a client registered under one of them is used.

Built-in clients register themselves when their library is linked and initialized; applications register custom clients before creating catalogs.
