Detailed Description

An IncrementalAppendScan that delegates PlanFiles() to the REST catalog server.

Scans without an exclusive start snapshot, including an inclusive root snapshot, return NotSupported.

IncrementalChangelogScan is not delegated because the REST planTableScan response only carries FileScanTask objects; reconstructing ChangelogScanTask entries (AddedRowsScanTask vs DeletedDataFileScanTask) requires per-snapshot operation metadata that the server does not return. Changelog scans always plan locally.
