Detailed Description

template<typename T>
class iceberg::Iterator< T >

A pull-based iterator whose reads may fail.

Iterator implementations own any resources needed to produce values. Destroying an iterator releases those resources, including when iteration stops before reaching the end. Iterators are not thread-safe unless an implementation explicitly says otherwise. Once Next() returns an error or std::nullopt, the iterator is terminal. Subsequent calls return the same terminal result without invoking the implementation again.
