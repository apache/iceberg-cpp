◆ Select()

MetadataScanBuilder & iceberg::MetadataScanBuilder::Select ( const std::vector< std::string > &  columns)

Select names using the current CaseSensitive() setting.

Columns are returned in schema order; unknown names are ignored. An empty list selects no columns and * selects all columns. Nested names use dots; selecting a map value selects the whole map, while selecting only its key fails.
