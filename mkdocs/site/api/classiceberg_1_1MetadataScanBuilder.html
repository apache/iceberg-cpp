Detailed Description

Configure a scan over a metadata table.

Builders are created by MetadataTable::NewScan(), and the metadata table must outlive the builder.

ICEBERG_ASSIGN_OR_RAISE(auto builder, snapshots_table->NewScan());
ICEBERG_ASSIGN_OR_RAISE(auto stream, builder->Select({"snapshot_id"}).Build());

MetadataScanBuilder & iceberg::MetadataScanBuilder::AsOfTime ( int64_t  timestamp_millis)

Request this scan to use the most recent snapshot as of the given time.

The snapshot is resolved on the branch set by UseRef(), or main if no branch is set. Only metadata tables that support time travel accept a timestamp; Build() returns NotSupported otherwise.

◆ Select()

MetadataScanBuilder & iceberg::MetadataScanBuilder::Select ( const std::vector< std::string > &  columns)

Select columns by name; nested columns use dot-separated paths.

Columns are returned in schema order, and names that match no column are ignored. An empty list selects no columns; * selects all columns. Names are resolved immediately, using the current CaseSensitive() setting. Selecting a map's value returns the whole map; selecting only its key is an error.

Parameters
columnsColumn names from the metadata table's schema.
